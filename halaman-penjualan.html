Pertanyaan yang sering diajukan

Apa maksudnya "BYOK" dan kenapa saya butuh API key sendiri?

BYOK = Bring Your Own Key. Aplikasi ini tidak punya server perantara — browser-mu bicara langsung ke Anthropic (pembuat AI Claude) memakai API key milikmu. Artinya: datamu tidak pernah lewat pihak ketiga, tidak ada langganan bulanan ke kami, dan kamu hanya membayar AI sesuai pemakaian. Panduan membuat key (5 menit) sudah termasuk di semua paket.

Berapa biaya pemakaian AI-nya?

Kamu isi saldo di Anthropic mulai $5 (±Rp 80 ribu). Satu caption/script biasanya hanya beberapa sen — saldo $5 umumnya cukup untuk ratusan konten. Aplikasi juga menyediakan pilihan model hemat.

Apakah ini langganan?

Bukan. Sekali bayar, aplikasi jadi milikmu selamanya. Yang berbayar sesuai pemakaian hanyalah token AI ke Anthropic (bukan ke kami).

Di mana data saya disimpan?

Semuanya — jurnal, profil kepribadian, kalender konten, API key — tersimpan lokal di browser perangkatmu. Tidak ada yang diunggah ke server kami (karena memang tidak ada servernya). Fitur backup satu klik tersedia di dalam aplikasi.

Apakah hasil tes kepribadiannya akurat?

Aplikasi memakai kerangka psikometrik standar (Big Five, MBTI, DISC, Enneagram) dan menampilkan hasil sebagai spektrum dengan tingkat keyakinan — bukan label mutlak. Ini alat refleksi & pengembangan diri, bukan diagnosis psikologis profesional.

Bagaimana saya menerima produknya setelah membayar?

Kamu akan menerima file aplikasi + panduan lengkap via email/tautan unduhan, biasanya dalam beberapa menit setelah pembayaran terkonfirmasi.
