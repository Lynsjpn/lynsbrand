🔗 Cara Menyambungkan ke Canva

Jalur cepat (manual, 30 detik):
1. Klik 🪄 Salin Prompt Canva Magic Design di atas.
2. Klik 🎨 Buka Canva → di Canva, ketik prompt di kolom pencarian AI ("Apa yang akan kamu desain?") atau buka Magic Design → tempel prompt → Canva membuatkan beberapa opsi desain sesuai DNA desainmu.

Jalur otomatis penuh (via Make.com):
1. Di Make.com buat skenario: Webhook → Canva (modul "Create Design from Brand Template" / "Autofill Template").
2. Siapkan Brand Template di Canva dengan field teks: judul, subjudul, cta.
3. Isi URL webhook di menu ⚡ Otomatisasi — tombol "Kirim ke Webhook" di atas akan mengisi template Canva-mu otomatis dengan copy & spesifikasi desain.

💬 Tes Kepribadian

Dua jalur: 🧬 Lab Kepribadian Pro (bank soal lengkap ala asesmen HR — tanpa API key, hasil detail + riwayat tersimpan) dan 💬 Tes Interaktif AI (12 pertanyaan adaptif).
⚠️ Alat refleksi & pengembangan diri, bukan diagnosis psikologis profesional.

🧬 Lab Kepribadian Pro — Asesmen Lengkap ala HR

5 asesmen standar dengan skoring psikometri baku (tanpa AI, tanpa API key): MBTI 60 soal (16 tipe + fungsi kognitif + ranking populasi + profesi per tipe), Big Five/OCEAN 50 soal, DISC 28 soal, RIASEC/Holland 36 soal, dan EQ 20 soal. Setiap hasil otomatis terarsip ke riwayat permanen, hasil tes online (16Personalities, SPI, dll.) juga bisa dicatat, dan semuanya bisa digabung menjadi laporan siap cetak/PDF.

💬 Tes Interaktif (12 Pertanyaan Adaptif)

Jawab dengan jujur & spontan — tidak ada jawaban benar/salah. Di akhir, hasil bisa disimpan sebagai Profil Kepribadian.

✍️ Analisis Tulisan

Psycho-Stylometric Profiler — analisis berbasis bukti dari tulisanmu dengan 3 kerangka tervalidasi: Big Five (OCEAN), RIASEC/Holland Codes (pemetaan bakat & minat), dan Stylometric DNA (4 variabel LIWC: Analytical Thinking, Clout, Authenticity, Emotional Tone). Setiap kesimpulan disertai kutipan bukti dari teksmu, dan hasilnya termasuk Arahan Persona — panduan suara brand siap-pakai. Bisa untuk dirimu sendiri maupun memahami orang lain.
⚠️ Alat refleksi & pemahaman diri, bukan diagnosis psikologis profesional.

✍️ Deteksi dari Tulisan

Metode ala LIWC/Crystal: kepribadian terbaca dari pola bahasa — kata fungsi, nada emosi, dan pola sosial dalam tulisan. Tempelkan tulisan bebas apa pun: chat panjang, caption, email, jurnal, esai (min. 150 kata; makin banyak & makin spontan tulisannya, makin akurat).

🔄 Sinkron ke Notion (Content Bank)

Kirim status & draft dari kalender ini kembali ke database 📚 Content Bank di Notion, lewat webhook Make yang sama. Item hasil impor membawa notion_id, jadi Make memperbarui baris yang ada (bukan bikin duplikat). Payload: {tipe:"notion_sync", notion_id, judul, status, tanggal, platform, jenis, catatan_riset, draft_ai}. Skenario Make-nya perlu dibuat sekali — lihat PANDUAN-SINKRON-NOTION.md.

⚠️ Tiap item = 1 operasi Make. "Sinkron Semua" atas 52 item = 52 operasi — perhatikan kuota bulanan paket gratis Make (1.000 ops). Karena webhook dikirim no-cors, browser tidak bisa membaca balasan: aplikasi hanya melaporkan "terkirim", bukan "berhasil disimpan di Notion". Cek riwayat eksekusi di Make untuk memastikan.

📦 Ekspor

⚠️ Pulihkan Backup menimpa SEMUA data. Untuk sekadar menambah ide dari Content Bank tanpa menghapus yang ada, pakai tombol di bawah.

⚙️ Pengaturan

Aplikasi ini memanggil Claude API langsung dari browser-mu. API key hanya disimpan di browser ini (localStorage) dan tidak dikirim ke mana pun selain api.anthropic.com.

Belum punya? Buat di platform.claude.com → API Keys.

🔒 Cukup dimasukkan sekali: key tersimpan berlapis di browser ini dan otomatis dipakai terus — tidak perlu diisi ulang tiap buka, dan tidak hilang saat aplikasi diperbarui. Agar tetap ingat, gunakan satu alamat yang sama (situs live-mu, bukan file lokal) di browser yang sama. Tombol 💾 Backup Semua Data di menu Otomatisasi juga menyimpan key ini.

🔐 Perlindungan API Key

Key disalin otomatis ke beberapa tempat penyimpanan di perangkat ini, dan dipulihkan sendiri kalau salah satunya hilang. Yang tetap bisa menghapusnya: kamu membersihkan data situs lewat pengaturan browser, memakai mode penyamaran, atau berpindah ke alamat situs / browser / perangkat lain (penyimpanan browser selalu terikat pada satu alamat). Untuk kasus itu, jaring pengamannya adalah ☁️ Sinkron Cloud di bawah.

☁️ Sinkron Cloud (antar perangkat)

Simpan API key + semua akun, kalender, bank materi & template secara online supaya bisa dibuka di PC lain atau HP tanpa memasukkan ulang. Datamu dienkripsi di perangkat ini dengan Kode Sinkron rahasiamu sebelum dikirim — server hanya menyimpan versi teracak dan tidak bisa membacanya. Perubahan tersimpan otomatis ke cloud.

⚠️ Kalau lupa Kode Sinkron ini, data di cloud tidak bisa dibuka lagi (tidak ada cara memulihkannya — itulah yang membuatnya aman). Simpan di tempat aman.

Di perangkat baru (PC lain / HP)? Masukkan Kode Sinkron yang sama, lalu klik Pulihkan — semua data (termasuk API key) akan tertarik otomatis. ⚠️ Ini menimpa data di perangkat ini.
